# 背景素材

应用已经内置 5 套可直接使用的背景。你可以用同名文件替换它们，刷新页面后即可生效：

- `ivory-paper.svg`：绢光信笺
- `night-sky.svg`：星夜鎏金
- `celadon-mist.svg`：青岚山色
- `rose-paper.svg`：绯页心事
- `amber-glow.svg`：午后琥珀

建议尺寸 1600 × 2200，格式可使用 SVG、JPG、WebP 或 PNG。若要换成其它扩展名，请同步修改 `public/blessing.css` 中对应主题的 `--theme-background` 地址。

注意：背景图建议控制在 600KB 以内，并避免包含客户姓名等隐私信息。
